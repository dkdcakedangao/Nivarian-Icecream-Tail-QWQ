# 糕糕的简易人物动画框架

用于 RimWorld 1.7，通过 LumiParticle／RimUnity 入口，播放 MA 格式 JSON 中的双人人物动画。目的是在无需安装 Melee Animation的情况下，实现简易的双人动画。

当前支持身体、头部、双手，以及原版衣物／头发跟随；不播放独立武器、火花、文字、轨迹或裁切效果。后续会增加新功能喵！

关于入口的介绍什么的，实在是有点麻烦，就麻烦GPT老师帮忙介绍了喵。

## 一、配置动画

1. 将 JSON 放入模组根目录的 `Animations/`。
2. 在 `1.7/Defs/AnimationDefs/` 新建动画 Def，可参考现有 `PawnAnimations.xml`：

```xml
<Defs>
  <NivarianIcecreamTail.PawnAnimationDef>
    <defName>MyCharacterAnimation</defName>
    <jsonPath>Animations/my_animation.json</jsonPath>
    <roles>
      <li>
        <body>BodyA</body>
        <head>BodyA/HeadA</head>
        <handsRoot>PawnAHolding</handsRoot>
      </li>
      <li>
        <body>BodyB</body>
        <head>BodyB/HeadContainer/HeadB</head>
        <handsRoot>PawnBHolding</handsRoot>
      </li>
    </roles>
    <ignoredRoots>
      <li>Juzhong</li>
      <li>HandGrabSparks</li>
      <li>WeaponACutoff</li>
      <li>QuestionMark</li>
    </ignoredRoots>
  </NivarianIcecreamTail.PawnAnimationDef>
</Defs>
```

提示喵！节点路径必须与 JSON 的完整 `Path` 一致；示例路径需要按自己的动画调整。两个 `roles` 依次对应施法者和目标，头部必须位于各自身体层级下，`handsRoot` 可省略。非人物节点放进 `ignoredRoots`，其子节点也会被忽略；未绑定或不支持的节点／属性会报错。

## 二、开始与推进播放

技能侧持有一个 `PawnAnimationSession`，示例：

```csharp
PawnAnimationDef def = DefDatabase<PawnAnimationDef>.GetNamed("MyCharacterAnimation");
Vector3 root = caster.Position.ToVector3ShiftedWithAltitude(caster.DrawPos.y);
bool mirror = target.Position.x < caster.Position.x;
PawnAnimationSession session = PawnAnimationSession.Start(
    def, caster, target, 0f, 0, mirror, root);
```

双方应已生成在同一地图。`Start` 失败返回 `null`，技能侧自行决定取消还是采用简化表现。

由活动 Job 每个游戏 Tick 调用一次 `session.Advance()`，不要让双方各调用一次。框架关闭 Animator 自动更新，以游戏 Tick 推进，因此暂停会停止、加速会加快，离屏仍能继续。

| 会话入口 | 用途 |
|---|---|
| `Start(def, caster, target, elapsed, cursor, mirror, root)` | 创建播放；新播放的 `elapsed`、`cursor` 均为 0 |
| `Advance()` | 推进一个游戏 Tick，并更新姿态与音效 |
| `Finished` | 是否已到动画结尾 |
| `Alive` | 本体播放句柄是否仍有效 |
| `Elapsed`、`SoundCursor` | 已播放时间、下一个待处理音效的位置 |
| `Mirror`、`RootPosition`、`Clip.Def` | 镜像、固定世界锚点与动画定义 |
| `Dispose()` | 解绑人物并释放播放资源；可重复调用 |

完成、中断、死亡、离图或句柄失效时，技能侧必须调用 `Dispose()` 并清空自己的会话引用。框架本身不负责锁定 Job、目标保护或伤害结算，这些由技能侧管理。

需要存档恢复时，保存动画 Def、参与者、`Elapsed`、`SoundCursor`、`Mirror` 和 `RootPosition`，引用解析完成后重新调用 `Start`。不要直接保存会话、Animator 或材质；已播放音效会按时间和游标跳过。

## 三、代码入口与职责

以下文件均位于本文同级的 `Animation/` 目录。

| 文件／入口 | 职责 |
|---|---|
| `PawnAnimationData.cs`：`PawnAnimationDef`、`CachedPawnAnimation.Get` | XML 配置、首次读取 JSON、校验并缓存曲线和控制器 |
| `NativeAnimationRig.cs`：`Seek`、`Advance`、`ReadPose` | 创建人物层级、采样动画，转换矩阵并处理镜像 |
| `PawnAnimationSession.cs`：`PawnAnimationSession`、`PawnAnimationActor.Capture` | 管理一次播放，记录双方身体／头部／双手姿态快照 |
| `PawnAnimationRendering.cs`：`Bind`、`Unbind`、`SetMatrix`、`DrawHands` | 将姿态接入原版人物绘制，处理独立头部与双手 |
| `PawnAnimationGraphics.cs`：`HandMaterial`、`GetMesh` | 生成手部贴图，缓存 UV 翻转和负缩放绕序修正网格 |
| `MeleeAnimationInterlock.cs` | MA 存在时，防止其接管正在使用 CA 的双方或重复绘制 |
| `Skill3NativeAnimation.cs` | 月牙叉炮的接入示例：Job 驱动、状态查询、清理及存档恢复 |
| `Skill3DeferredDeath.cs` | 月牙叉炮专用的延迟死亡归属记录，不属于动画解码逻辑 |

资源入口为 `IcecreamTailMod.AssetBundleRoot`；`1.7/Data/RimUnity/catalog.json` 登记最小骨架，`ActorRig.json` 提供 Animator 容器，会话通过 `LumiParticleEffects.SpawnAnimator` 创建实例。通常新增同格式人物动画不需要修改这两个资源文件。

## 四、支持的动画内容

- 人物层级、位移、欧拉角、缩放、朝向、可见性与染色；双手支持 FlipX／FlipY。真实人物朝向由 `PawnBody.Direction` 决定，不叠加编辑器人物 Sprite 翻转。
- 默认值、关键帧切线／权重，以及 Clamp、Loop、PingPong 曲线；整段播放本身不循环。
- 音效事件格式为 `Audio;SoundDef名称;0,0,0;1;1;False`，遵守模组的彩蛋音效开关。其他偏移、音量、音调或跟随参数暂不支持。
